How to tell the two plots apart and when to use each:
  - Learning curve: x-axis is training set SIZE, hyperparameters fixed. Answers 'would more data help?'
  - Validation curve: x-axis is a HYPERPARAMETER, training set size fixed. Answers 'how complex should
    the model be, given the data already in hand?'
  - A high-bias model's learning curve plateaus early with train and CV close together and both low.
  - A high-variance model's learning curve keeps a wide train-CV gap even at full data size.
