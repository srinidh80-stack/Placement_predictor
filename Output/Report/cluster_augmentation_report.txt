FEATURE AUGMENTATION WITH CLUSTERING REPORT
================================================================================

on validation, never on the label) adds cluster-membership and centroid-distance
columns to 39 base features. Evaluated on 5,001 validation rows.

Conclusion:
  2 variant(s) improved and 0 degraded beyond noise (CI excludes zero).

Methodological Insights:
  1. Cluster features can only help a model that cannot already represent the
     underlying non-linear manifold structure.
  2. Confidence intervals that cross zero demonstrate that measured gains are
     indistinguishable from sample variance.
  3. Leakage safeguard: K-Means centroids fixed strictly at training time.
