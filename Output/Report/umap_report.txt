4. COMPARATIVE SUMMARY: t-SNE vs UMAP (SLIDE 16):
   ---------------------------------------------------------------------------
   Aspect                    | t-SNE                  | UMAP                  
   ---------------------------------------------------------------------------
   Mathematical Basis        | Probability / KL Div   | Topology / Fuzzy Sets 
   Speed on Large Data       | Slower (O(N^2))        | Substantially faster  
   Global Structure          | Largely not preserved  | Somewhat better preserved
   Key Hyperparameters       | perplexity             | n_neighbors, min_dist 
   New-point Embedding       | Must re-run on full data | Supports transform()  
   ---------------------------------------------------------------------------

5. COMPARISON WITH LINEAR REGRESSION (SLIDE 19):
   ---------------------------------------------------------------------------
   Aspect                    | t-SNE / UMAP           | Linear Regression     
   ---------------------------------------------------------------------------
   Learning Type             | Unsupervised           | Supervised            
   Goal                      | Visualize high-D in 2D | Predict continuous y  
   Input Needed              | Features only (no label) | Features X and target y
   Output                    | 2D/3D plot coordinates | Predicted numeric value
   Distances                 | Only LOCAL meaningful  | Directly meaningful   
   ---------------------------------------------------------------------------
