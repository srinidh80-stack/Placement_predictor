Mathematical Formulations & Geometric Intuition

Key theoretical derivations from Module 2 Session 19.

Theory Reference

Ridge Regression (L2 Penalty)

J(w) = ||Xw - y||² + λ||w||²&sub2; ⟶ ŵ = (XᵀX + λI)‾¹Xᵀy

  • Multicollinearity Fix: Adding λI guarantees XᵀX + λI is always non-singular and invertible.
  • Smooth Constraint Ball: Shrinks all weights proportionally; none become exactly zero.

Lasso Regression (L1 Penalty)

J(w) = ||Xw - y||² + λ||w||&sub1; ⟶ ŵⱼ = sign(w̃ⱼ)·max(|w̃ⱼ| - λ/2, 0)

  • Diamond Geometry: Loss contours touch diamond corners on axes, setting irrelevant weights to exact 0.
  • Automatic Feature Selection: Soft-thresholding operator eliminates noisy predictors.

Elastic Net (L1 + L2 Blended)

J(w) = ||Xw - y||² + λ[ α||w||&sub1; + (1-α)||w||²&sub2; ]

  • Group Sparsity: Correlated feature clusters are selected or dropped together.
  • Tunable Mixing Ratio: α = 1 (Pure Lasso), α = 0 (Pure Ridge), 0 < α < 1 (Blended).

Bias-Variance Trade-off

E[(y - ŷ)²] = Bias²(ŷ) + Var(ŷ) + σ²_ε

  • Overfitting (High Variance): Memorizes noise; large train-validation gap.
  • Regularization Remedy: Slightly increases bias while drastically reducing variance for optimal generalization.
