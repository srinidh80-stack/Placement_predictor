Data Leakage

Demonstrating pre-split scaling leakage, feature selection leakage, and pure noise inflation.

1. Pre-Split Scaling 2. Selection Leakage 3. Noise Inflation

💡 Data Leakage Insights

  • Scaling Leakage: Computing global $\mu, \sigma$ before splitting lets test information bleed into train estimators.
  • Selection on Full Data: Picking top features before splitting yields spuriously high CV scores on pure noise.
  • Pipeline Encapsulation: All transformers must be fit strictly within training folds.

Cross-Validation

Holdout variance vs 5-fold CV, stratification stability on sorted data, and train-CV gap.

1. Holdout vs 5-Fold 2. K-Fold Stability 3. Stratification

💡 Cross-Validation Insights

  • Holdout Seed Sensitivity: A single 80/20 split has high sampling variance depending on the random seed.
  • StratifiedKFold: Preserves placement class balance across all folds, essential when sorted by college tier or GPA.
  • Generalization Gap: Measures difference between train score and out-of-fold validation score.

Nested Cross-Validation

Measuring selection optimism in non-nested CV vs unbiased nested outer fold evaluation.

1. Selection Optimism 2. 5x3 Nested Loops 3. Sample Size Effect

💡 Nested CV Insights

  • Optimistic Bias: Tuning hyperparameters on the same folds used for final scoring overestimates true performance.
  • Inner Loop: Tunes hyperparameters; Outer Loop: Provides an honest estimate of generalization error.
  • Sample Size: Selection optimism is pronounced on smaller samples and diminishes with large N.

Threshold Tuning

Beyond default 0.5: Confusion matrices across thresholds and cost-sensitive optimization.

1. Cutoff Sweeps 2. Cost Matrix 3. Asymmetric Penalties

💡 Threshold Tuning Insights

  • Threshold Shift: Lowering threshold catches more positive cases (high recall) at cost of false positives.
  • Asymmetric Cost: Missing a candidate who would be placed (FN) may be 5x more costly than false alarm (FP).
  • Optimal Cutoff: Pinpoints the exact probability threshold that minimizes total business loss.

ROC & PR Curves

Evaluating ranking discrimination and class imbalance sensitivity (10% and 3% minority rates).

1. ROC AUC 2. PR AUC 3. Imbalance Contrast

💡 ROC vs PR Insights

  • ROC Invariance: ROC curves are insensitive to changes in class prevalence.
  • PR Curve Precision: Under severe class imbalance, PR curves expose false alarm rates that ROC obscures.
  • No-Skill Baseline: ROC baseline is always 0.5; PR baseline equals the positive class prevalence.

Search Benchmark

Grid Search vs Random Search across 2D Decision Trees and 5D LightGBM models under equal budgets.

1. 2D Grid Sweep 2. 5D Random Search 3. Budget Efficiency

💡 Search Strategy Insights

  • Curse of Dimensionality: Grid search becomes exponentially slow as hyperparameters increase ($K^D$).
  • Random Search: Explores distinct values on each axis, finding superior configurations in fewer trials.
  • LightGBM 5D: Demonstrates practical efficiency over learning rate, tree depth, and leaf parameters.

Learning Curves

Diagnosing high bias vs high variance across dataset sizes and decision tree depth sweeps.

1. 3 Model Regimes 2. Training Size N 3. Validation Curve

💡 Bias-Variance Curves Insights

  • Learning Curve: Varies training sample size $N$. Answers: "Will gathering more data improve the model?"
  • Validation Curve: Varies a hyperparameter (e.g. tree depth). Answers: "What is the optimal complexity?"
  • Gap Diagnosis: High variance keeps a large train-CV gap; high bias plateaus early with both low.

Bayesian Optimization

Optuna Tree-structured Parzen Estimator (TPE) vs Random Search across 30 trials with 5-fold CV.

1. Optuna TPE 2. Running Best Score 3. Per-Trial Trajectory

💡 Bayesian Optimization Insights

  • Surrogate Modeling: Learns probability distribution of top parameters conditioned on past evaluation history.
  • TPE Sampler: Models good vs poor trials separately to focus sampling on high-probability improvement regions.
  • Exploration vs Exploitation: Balances testing promising areas against probing unexplored spaces.

Calibration & Significance

Probability calibration (Isotonic/Sigmoid), McNemar's paired test, and 2,000 bootstrap AUC difference resamples.

1. Reliability Curves 2. McNemar's Test 3. Bootstrap AUC CI

💡 Calibration & Significance Insights

  • Calibration: When model predicts 70% probability, exactly 70% of those candidates should be placed.
  • Brier Score: Mean squared error of probabilities; minimized by well-calibrated confidence.
  • McNemar & Bootstrap: Evaluates paired disagreement rows to prove real statistical difference vs random noise.
