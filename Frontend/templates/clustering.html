K-Means Clustering

First group: Inertia (WCSS), Elbow inflection, and Silhouette score optimization.

1. Elbow Curve 2. Silhouette 3. PCA Clusters

💡 K-Means Concepts

  • Within-Cluster Sum of Squares (Inertia): Measures compactness $\sum_{k=1}^K \sum_{x \in C_k} \|x - \mu_k\|^2$.
  • Silhouette Coefficient: Measures separation quality $\frac{b - a}{\max(a, b)} \in [-1, 1]$.
  • Zero-Leakage Clustering: Trained purely on scaled skills & academics with target withheld.
📁 Folder 02 Hover for details ℹ️

Hierarchical Clustering

Second group: Agglomerative bottom-up tree, 4 linkage rules, cophenetic correlation, and dendrograms.

1. Ward Linkage 2. Cophenetic Corr 3. Dendrogram Cuts

💡 Hierarchical Clustering Insights

  • Linkage Methods: Ward (variance-minimizing), Complete (max distance), Average (mean), Single (min distance).
  • Chaining Effect: Single linkage forms elongated chains; Ward produces balanced cohorts.
  • Adjusted Rand Index (ARI): Quantifies statistical agreement between K-Means and Ward tree cuts.

Feature Augmentation

Third group: Enhancing supervised models with cluster assignments and centroid distance vectors.

1. Distance Features 2. Linear Gain 3. Tree Impact

💡 Feature Augmentation Insights

  • Radial Distances: Distance-to-centroid features linearize complex non-linear neighborhoods for linear models.
  • Tree vs Linear: Decision trees already find axis-aligned cuts, so linear models gain more substantial boost.
  • Zero Leakage: Fitted strictly on training folds to prevent target information bleeding.

PCA Dimensionality

Fourth group: Scree plot, cumulative variance explained, 2D placement projection, and loading biplot.

1. Scree Plot 2. 2D Projection 3. Feature Loadings

💡 PCA Insights

  • Variance Maximization: Orthogonal axes capturing maximum geometric spread across skills and academics.
  • Standardization Pitfall: Features must be standardized so high-scale variables don't dominate variance.
  • Biplot Loadings: Visualizes which academic scores drive PC1 and PC2.

DBSCAN Density

Fifth group: k-distance elbow curve, density reachability, arbitrary shapes, and noise detection.

1. k-Distance Elbow 2. Noise Isolation 3. Two-Moons Test

💡 DBSCAN Insights

  • Density Reachability: Core points with $\ge \text{min\_samples}$ within $\epsilon$ radius.
  • Noise Robustness: Isolates atypical records without forcing them into artificial clusters.
  • Arbitrary Shapes: Captures non-spherical geometric structures where K-Means fails.
📁 Folder 06 Hover for details ℹ️

t-SNE Manifold

Sixth group: Non-linear manifold embedding, Student-t heavy tails, and perplexity sweep diagnostics.

1. Placement 2D 2. Perplexity Sweep 3. Distortion Trap

💡 t-SNE Insights

  • Local Neighborhoods: Minimizes KL divergence between high-D Gaussian and low-D Student-t distributions.
  • Crowding Problem: Solved by Student-t distribution's inverse-square heavy tail.
  • Pitfall: Cluster sizes and distances in t-SNE are non-linear artifacts, not absolute physical distances.
📁 Folder 07 Hover for details ℹ️

UMAP Projection

Seventh group: Riemannian geometry, fuzzy simplicial sets, and out-of-sample projection transform.

1. 2D Placement 2. n_neighbors Grid 3. New Point Transform

💡 UMAP Insights

  • Topological Manifolds: Better preserves global continuum structure compared to t-SNE.
  • Out-of-Sample Transform: Enables projecting newly enrolled candidate records into fitted manifold.
  • Fuzzy Simplicial Sets: Algebraic topology formulation offering orders of magnitude faster execution.
📁 Folder 08 Hover for details ℹ️

Anomaly Detection

Eighth group: Isolation Forest, random recursive partitioning, anomaly scores, and profile audits.

1. Isolation Trees 2. Score Distribution 3. Student Profiles

💡 Anomaly Detection Insights

  • Isolation Mechanism: Anomalies require fewer random splits to isolate in shallow tree branches.
  • Path Length Metric: Normalized path length $c(n)$ directly yields an anomaly probability score.
  • Audit Archetypes: Detects discordant profiles (e.g. high CGPA with zero test scores or anomalous backlogs).
