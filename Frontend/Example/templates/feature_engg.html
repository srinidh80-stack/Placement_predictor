💡 Linear Regression Overview

  • Continuous Prediction: Estimates placement salary packages (LPA) on placed candidates.
  • Normal Equation: Closed-form exact solution θ̂ = (XᵀX)⁻¹Xᵀy.
  • Batch Gradient Descent: Iterative MSE minimization θ := θ − α∇J(θ).

Normal Equation (Closed-Form)

θ̂ = (XᵀX)⁻¹ Xᵀy

  • Exact closed-form mathematical solution in a single matrix inversion step.
  • Used by Scikit-Learn (LinearRegression) for fast convergence.
  • Requires no learning rate hyperparameter tuning.

Batch Gradient Descent (Iterative)

θ := θ − α · ∇J(θ)

  • Iterative optimization updating parameters over full-batch epochs.

The Sigmoid Activation Function

σ(z) = 1 / (1 + e⁻ᶻ)

  • Squashes any linear score z = θᵀx into a valid probability in (0, 1).
  • Decision boundary occurs at z = 0 where σ(z) = 0.5 (50% threshold).

Cross-Entropy Loss (Log Loss)

J(θ) = −(1/m) Σ [y·log(ŷ) + (1−y)·log(1−ŷ)]

  • Replaces MSE because MSE + Sigmoid produces non-convex cost surfaces.
  • Convex with a single global minimum, harshly penalizing confident wrong predictions.
